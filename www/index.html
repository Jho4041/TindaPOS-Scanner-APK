Receipt printer type

Thermal receipt printers do not need drivers. Nearly all of them (Epson, Xprinter, Rongta, MUNBYN, GOOJPRT, HPRT, Sunmi, Bixolon, Citizen, Star in ESC/POS mode) use the same ESC/POS commands. Pick your model type, paper width and cutter. This applies to both USB and Bluetooth printers.

58mm paper is usually 32 characters, 80mm is 48.

Wireless scanner (another phone to this device)

Use the separate TindaPOS.ph Scanner app on another phone. Each barcode it scans is sent over Wi-Fi and added to the cart here. Both devices must be on the same Wi-Fi.

On a Windows PC, run the TindaPOS.ph Wireless Scanner Helper (windows-helper folder), click the barcode box in TindaPOS.ph, then scan with the Scanner app. (The TindaPOS.ph Windows app does not need the helper.)

Use this phone as a scanner

Turn this phone into a camera barcode scanner for another TindaPOS.ph device (your main tablet or phone). Each barcode you scan is sent to it over Bluetooth and added to the cart.

Set up once: 1) Pair the two phones in Android Bluetooth settings. 2) On the main device go to Settings, Find devices, tap this phone and choose Use as scanner. 3) On this phone tap Start scanner mode.
